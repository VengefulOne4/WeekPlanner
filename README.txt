НЕДЕЛЬНОЕ РАСПИСАНИЕ — ДЕСКТОПНАЯ ВЕРСИЯ
==========================================

Файлы (должны лежать в одной папке):
  - desktop_app.py       — запускающий скрипт
  - weekly_planner.html  — само приложение (вёрстка + логика)

УСТАНОВКА
---------
Нужен Python 3.8+ и библиотека pywebview.

    pip install pywebview --break-system-packages

Если команда pip не работает, попробуйте pip3 вместо pip.

Дополнительно по ОС:

  Windows:
    Обычно всё работает "из коробки" — pywebview использует
    Edge WebView2, который уже встроен в Windows 10/11.

  macOS:
    Тоже работает сразу — используется системный WebKit.

  Linux:
    Может понадобиться системный пакет с WebKit2GTK, например (Ubuntu/Debian):
        sudo apt install python3-gi gir1.2-webkit2-4.0
    (название пакета отличается в зависимости от дистрибутива)

ЗАПУСК
------
    python desktop_app.py

Откроется отдельное окно с приложением — без адресной строки браузера.
Данные (задачи и категории) сохраняются локально в этом окне так же,
как и в браузерной версии, и остаются между запусками.

СБОРКА В ОДИН .EXE / ПРИЛОЖЕНИЕ (опционально)
----------------------------------------------
Если хотите единый исполняемый файл без установки Python на другом
компьютере, можно собрать через PyInstaller:

    pip install pyinstaller --break-system-packages
    pyinstaller --onefile --add-data "weekly_planner.html;." desktop_app.py

(на macOS/Linux вместо ";." используйте ":.")

Готовый файл появится в папке dist/.
